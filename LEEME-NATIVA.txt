AURA Inteligencia Artificial 3.4.0 — Escritorio nativo Windows 10 x64

Ventana propia Qt. No inicia un navegador externo ni un servidor web para la interfaz. El explorador integrado de Internet es opcional. Motor CPU Qwen2.5-Coder 1.5B Q4_K_M con bibliotecas SSE4.2/x64; no utiliza AVX ni CUDA para generar texto. Ajuste inicial: 2 hilos. El i5 de primera generación de destino no se ha probado físicamente.

La carga por proceso libera memoria al terminar cada respuesta. AURA prepara una caché local al iniciar para acelerar consultas posteriores. Se puede borrar desde Pensamiento y ajustes. El modo Temporal no guarda contexto en esa caché. Reduce consumo en reposo, pero carga y preparación pueden superar 3,5 segundos. La prueba nativa en frío registró unos 9,7 segundos hasta el primer texto. Con caché preparada, dos consultas cortas registraron unos 1,3 y 2,6 segundos en el equipo de prueba. No se garantizan esos tiempos en otra PC. No hay cuota de tokens; contexto y longitud son finitos.

Inicio: abre AURA. El video comienza automáticamente, sin botones ni textos superpuestos; el chat aparece al terminar la preparación. Escribe y pulsa Enviar. Conversación responde preguntas; Programación usa la carpeta elegida y pide aprobación antes de aplicar cambios. Terminal y compilación piden autorización para ejecutar comandos. Los modelos adicionales de esta versión deben ser Qwen2/Qwen2.5 Instruct ChatML GGUF. Otros formatos de conversación todavía no son compatibles.

Memoria: escribe recuerda: seguido del dato, o abre Memoria para agregar, editar, buscar, olvidar, exportar e importar. Puedes separar recuerdos generales y por proyecto. Las conversaciones se conservan y pueden reabrirse desde el historial. Temporal no guarda la conversación ni recupera memoria; funciona en Conversación. No guardes claves en los recuerdos. Los datos están en %LOCALAPPDATA%\AURA_IA. Un respaldo manual de esa carpeta conserva conversaciones y memoria. La clave cifrada de ElevenLabs solo se descifra bajo el usuario Windows que la guardó.

Asistente flotante: arrástralo, pulsa Abrir para mostrar AURA o Dictar para hablar. Ocultar lo desactiva; puedes recuperarlo en Pensamiento y ajustes. Su animación es ligera y no carga otro modelo.

Dictado offline: pulsa Dictar, habla y pulsa Terminar dictado; revisa la transcripción antes de Enviar. Incluye Vosk pequeño en español. Se escucha únicamente al pulsar el botón, con límite de 60 segundos. No se guardan grabaciones del micrófono. La prueba se hizo con audio sintético, no con tu micrófono físico.

Voz: Windows proporciona el respaldo offline. Para español, debe existir una voz española instalada en Windows. En Voz y audio puedes ajustar la voz, volumen y velocidad y escuchar el MP3 Kate proporcionado.

ElevenLabs: selecciona ElevenLabs con respaldo local, introduce tu API key dentro de la aplicación y pulsa Consultar mi cuenta y buscar Kate. Selecciona su voz o introduce su identificador y guarda. La clave se cifra con DPAPI de Windows. Nunca la envíes por chat. ElevenLabs necesita Internet y saldo o disponibilidad en la cuenta; el texto que se lee se envía al servicio. Si falla, se usa la voz local. No se ha probado una llamada real porque no se dispone de tu clave ni de tu identificador. No hay credenciales dentro del instalador.

Clonación local Kate: NO está terminada ni validada. El MP3 es una referencia, no un modelo. Se investigaron opciones para CPU; el candidato ligero NeuTTS Nano Spanish exige acceso con cuenta y aceptación de sus condiciones. La semejanza y velocidad en este i5 todavía deben comprobarse. No se presenta la voz Windows como clon de Kate.

Herramientas: incluye Python y PyInstaller para compilar proyectos Python. Cada proyecto puede necesitar dependencias adicionales. Activa habilidades desde Habilidades; no conceden permisos nuevos. El análisis binario es básico, no una suite completa REA.

El instalador no está firmado. Desinstalar conserva la información del usuario. Licencias incluidas en licencias. Aplicación independiente de OpenAI Codex.

Contexto: la barra permite elegir de 2048 a 8192 tokens; se recomiendan 4096 para el i5. Si activas la ampliación automática se puede usar hasta 8192 al necesitar más espacio. El historial completo sigue guardado; el modelo recibe el inicio de la tarea y los turnos recientes. Un texto que exceda incluso ese límite debe dividirse o consultarse por partes.

Arranque 3.0.1: el video aparece antes del chat y se reproduce durante la preparación del modelo. Al estar listo pasa al chat automáticamente. La pantalla del video no contiene controles ni requiere intervención. La interfaz principal es azul oscuro con navegación compacta e historial lateral.

AURAX 3.1: pulsa AURAX · Codificador en la barra lateral. Abre un proyecto, haz doble clic en un archivo para editarlo y usa Adjuntar a AURAX para enviarlo al agente. Los cambios se revisan antes de escribir. El panel permite verificar y ejecutar Python y generar EXE con PyInstaller; esos procesos requieren autorización. Revisar código IA carga un bloque de la respuesta como borrador sin guardarlo automáticamente. La consola muestra resultados reales y la aplicación distingue respuestas sin cambios de archivos aplicados. No es el servicio OpenAI Codex: utiliza el modelo local seleccionado y conserva sus límites.

Novedades 3.2: Explorador de Internet en el menú lateral. Ante certificados inválidos permite aceptar expresamente bajo tu responsabilidad, cuando Chromium lo permite. Cancelar es la opción inicial. La excepción y los datos de navegación duran la sesión del explorador y se eliminan al cerrar. No desactiva TLS globalmente ni modifica certificados de Windows. Las descargas y permisos de dispositivos están bloqueados en esta versión.

C/C++: abre un archivo .cpp o .c en AURAX y pulsa Verificar o Compilar EXE. Ejecutar usa el EXE previamente compilado en dist. Incluye w64devkit 2.11.0; los proyectos con varias unidades o dependencias requieren configuración adicional. Inno Setup: abre un script .iss y pulsa Crear instalador. Se pide autorización para ejecutarlo. Incluye Inno Setup 7.1.1 y sus licencias. El instalador de AURA también se genera con Inno Setup.

Bases SQL 3.3: abre Bases de datos SQL, elige un motor y completa los datos. SQLite solo requiere seleccionar un archivo existente. Los ajustes avanzados se muestran bajo demanda. La contraseña se utiliza en memoria durante la sesión del panel; no se guarda en archivos, conversaciones ni memoria del asistente. Desconectar elimina la referencia de la sesión. No se promete borrado criptográfico de la RAM.

Incluye conectores para SQL Server/Express (pyodbc; requiere controlador ODBC de 64 bits instalado en Windows), PostgreSQL (pg8000), MySQL/MariaDB (PyMySQL), SQLite y Oracle (oracledb Thin). Para otros motores utiliza un DSN ODBC de 64 bits compatible. El controlador y el servidor determinan las versiones admitidas; no se garantiza toda versión histórica o futura. Se probaron operaciones reales SQLite y la carga de los cinco conectores adicionales; los servidores remotos requieren prueba con tus equipos y cuentas.

Selecciona una tabla para ver columnas y tipos. Escribe una sola instrucción (hasta 12000 caracteres) y pulsa Ejecutar para revisarla. Permitir cambios habilita instrucciones de escritura con confirmación; DDL puede ser irreversible o confirmar automáticamente según el motor. El modo de consultas aplica filtros conservadores y usa lectura en SQLite y transacciones de lectura donde es posible. Utiliza una cuenta de solo lectura para imponer los permisos en el servidor; los filtros del cliente no sustituyen esos permisos.

Se muestran hasta 500 filas, 100 columnas y 2000 caracteres por celda. Exportar CSV guarda solo las filas visibles y no es un respaldo completo. Respaldo SQLite crea un archivo nuevo y verifica su integridad. Para respaldos/restauraciones de otros motores usa sus utilidades nativas y prueba la restauración en una base separada. Las operaciones SQL se ejecutan en segundo plano; los tiempos de espera dependen también del controlador. No cierres el programa mientras hay una operación activa.

Pedir ayuda a AURAX prepara un mensaje editable con el motor, la estructura seleccionada y el SQL del editor. No incorpora las filas obtenidas ni la contraseña de conexión. Revisa el mensaje y pulsa Enviar. Usar SQL de AURA carga su propuesta como borrador, nunca la ejecuta automáticamente. La habilidad Bases de datos SQL se incluye para orientar las propuestas. La conexión cifrada verifica certificados; las excepciones del explorador web no se aplican a bases de datos.

Lenguajes 3.4: AURAX reconoce JavaScript (.js/.mjs/.cjs), Java (.java), HTML5 (.html/.htm) y PHP (.php), además de Python, C/C++ y scripts de Inno Setup. Los mismos botones eligen la herramienta por la extensión. JavaScript usa Node.js 22.23.5; PHP usa PHP 8.4.28 por consola; Java usa Eclipse Temurin JDK 25.0.4.1. Las herramientas se inician únicamente al utilizarlas. Node tiene límite de heap de 256 MB, PHP 128 MB y Java 256 MB con dos procesadores activos. Son límites iniciales para trabajos pequeños; proyectos grandes pueden ejecutarse con ajustes propios desde Terminal.

Verificar revisa sintaxis en JavaScript/PHP y compila Java a .class. Compilar genera EXE para Python/C++ y .class para Java en build/aurax-java; JavaScript, HTML5 y PHP no se convierten automáticamente a EXE. Ejecutar corre el código o abre una vista previa local HTML5 dentro de AURA, sin servidor web. En HTML se hace una revisión de lectura básica, que no sustituye un validador completo. PHP de consola no crea un sitio web ni simula automáticamente una petición HTTP.

Los proyectos con bibliotecas externas necesitan sus dependencias. Node incluye npm; Java incluye herramientas del JDK. Terminal incorpora rutas de las herramientas incluidas sin modificar permanentemente Windows. Cada ejecución se revisa antes de autorizarse. Las habilidades Bases de datos SQL y Programación multilenguaje están disponibles en Habilidades; activarlas no concede permisos nuevos.
