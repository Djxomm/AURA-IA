# Asistente visual AURAX

Ilustración original creada para AURA mediante la herramienta integrada de generación de imágenes. Archivo del proyecto: `agente_ia/static/assets/aurax-companion.png`. Tiene transparencia y se carga una sola vez; la interfaz guarda una versión escalada en memoria.

Descripción de generación: personaje original tipo búho, azul marino y cobalto con detalles cian, ojos expresivos, gafas redondas y cuaderno de código; ilustración de píxeles, una sola pose, cuerpo entero, fondo transparente, sin texto, entorno ni marcas de agua. Se usa como asistente flotante de AURAX.

Prompt final utilizado con la herramienta integrada:

> Create a polished original desktop assistant mascot for AURAX, a friendly small blue owl-like coding companion. Single character centered, full body, front three-quarter view, large expressive eyes with subtle round cyan eyeglass-like rims, navy and cobalt feathers, bright cyan accents, tiny wings holding a small dark-blue code notebook with a simple cyan angle-bracket symbol. Clean charming pixel-art sprite aesthetic with crisp readable silhouette, carefully drawn restrained pixel shading, professional and friendly rather than babyish. Intended to display at 100 pixels tall on a Windows desktop. Transparent background, no rectangle, no environment, no ground shadow, no text or watermark, no brand logos. Leave generous transparent padding around the whole silhouette. One single idle pose only.
