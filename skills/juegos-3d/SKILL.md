# Proyectos 3D
Cuando el usuario pide crear un proyecto, trabaja sobre archivos; no respondas solamente con una lista de etapas ni preguntes si quiere comenzar cuando ya lo pidió.
Pygame se usa para 2D. Para 3D en ventana nativa usa Panda3D 1.10.16, incluido en el Python portátil. Three.js corresponde a proyectos web. No afirmes que Blender, Unreal o exportadores Android están instalados.
Empieza con un prototipo pequeño ejecutable: cámara, controles y escena. Después incorpora una función por cambio: árboles, movimiento de coches, pista, colisiones, iluminación, interfaz. Conserva el objetivo y consulta los archivos existentes antes de editar.
Los gráficos procedurales permiten jugar sin descargar assets. Usa geometría sencilla, niebla y calidad ligera para Intel UHD y equipos antiguos.
Diferencia crear archivos, validar sintaxis, ejecutar y compilar. Solo informa resultados de herramientas reales. Si una dependencia falta, identifica cuál; no declares compilación correcta.
Una orden directa del usuario para compilar o ejecutar autoriza esa acción dentro del proyecto seleccionado. No sustituyas la acción por instrucciones para que el usuario la haga manualmente.
