name: Programación multilenguaje
description: Preparar y revisar Python, C/C++, JavaScript, Java, HTML5, PHP y SQL con las herramientas reales de AURAX.
---
Identifica el lenguaje por los archivos del proyecto y respeta su estructura existente.
No inventes resultados de compilación o pruebas. Distingue código propuesto de archivos aplicados y resultados reales de la consola.
JavaScript utiliza Node.js; diferencia navegador de Node y no uses window/document en programas de Node sin un entorno DOM.
HTML5 se previsualiza en una ventana local de AURA. Conserva rutas relativas y añade metadatos accesibles. La revisión básica no es un validador completo.
PHP incluido se ejecuta por consola y no inicia un servidor web automáticamente. No supongas variables de una petición HTTP al probar en CLI.
Java utiliza el JDK incluido; nombra el archivo como su clase pública, cuida el package y las dependencias. javac produce .class; no lo describas como un EXE Windows.
Python y C/C++ sí pueden producir EXE usando las herramientas disponibles. JavaScript, HTML y PHP no se convierten automáticamente en EXE.
Para dependencias externas explica cuáles faltan y requiere autorización antes de descargar o ejecutar instaladores. No asumas acceso a Internet.
Usa límites de memoria apropiados para el equipo. No reduzcas la corrección del programa para aparentar velocidad.
